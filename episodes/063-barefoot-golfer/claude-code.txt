   네트워크 오류로 결과가 불명확하면 다시 생성하지 말고 멈춘다.

   음성이 이미 있으면 python aw.py timing 063 — 문장·글자 시각을 다시 계산 (크레딧 0).
   출력의 정렬 방식이 whisper 인지, 일치율이 80% 이상인지 확인. 아니면 이유(경고)를 보고한다.
   Whisper 는 config 의 timing.whisper_device(기본 cpu)로 돈다 — 20초 안팎. GPU 자동 전환·CUDA 설치를 시도하지 않는다.
   audio/pace.json 의 removed_seconds(줄인 쉼 길이)도 보고한다.

   이 편은 이미지마다 움직임 효과를 넣어 합성한다 (Grok 영상 대신, 2026-11-24 사용자):
   - zoom_in 천천히 다가감 · zoom_out 물러남 · push 감정 장면에서 깊게 다가감 · pan_left/right/up/down 가로지름 · drift 다가가며 옆으로 흐름
   - episode.yaml 의 still_motion(컷별 움직임)·focus([x, y] 0~1, 다가갈 지점 — 보통 얼굴·손)를 따른다. 없으면 이야기 단계에 맞춰 자동
   - 컷 사이 0.35초 디졸브, 확대 상한 1.16배(push 1.24배) — config clips.images_zoom_max / images_dissolve
