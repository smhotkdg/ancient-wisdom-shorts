# 이미지·영상 프롬프트 가이드

콘티(`conti.html`)의 프롬프트는 화풍 프리셋(`styles/*.yaml`) 문구 + 장면 설명 + 공통 규칙으로 자동 조립된다.
사용자는 복사해서 붙여 넣기만 하면 된다.

## ChatGPT (이미지)

1. **에피소드마다 새 대화**를 연다.
   - **한 번에 다 만들기**: 콘티 "GPT 모음" 탭의 **전체 복사**를 그대로 붙여 넣는다. 맨 앞에 진행 지시가 자동으로 붙어 있어서
     ChatGPT 가 묻지 않고 캐릭터 → 장면 순서로 바로 만든다. 한 번에 10장 제한이 있으면 1차·2차로 나눠 이어서 만들고,
     중간에 멈추면 "계속"만 보내면 된다 (`shorts/conti.py`의 `gpt_preamble`).
2. **캐릭터 기준 이미지부터**: 콘티의 "캐릭터" 프롬프트로 생성 → 마음에 들 때까지 → `images/char_<id>.png` 저장.
3. **장면 이미지**: 캐릭터 이미지를 첨부하고 장면 프롬프트 붙여넣기 → `images/sNN.png`.
   - 같은 장소가 이어지는 장면은 앞 장면 이미지도 함께 첨부하면 배경이 유지된다.
   - 세로 이미지로 요청 (프롬프트에 포함). 2:3으로 나와도 합성할 때 가운데 기준 9:16으로 자른다 → 좌우 끝 약 8%씩 잘린다.
4. 확인할 것: 글자·로고가 들어가지 않았는지, 인물 얼굴·옷이 기준과 같은지, 핵심 동작이 가운데 있는지. 주인공이 가운데 크게 나오는지 — 배경 인물은 장면에 맞을 때만 뒤쪽에 작게 몇 명(에피소드당 3장면 이하), 군중이 주인공을 가리면 다시 만든다 ([화면 인물 가이드](scene-people.md)).

## Grok (영상)

1. 장면 이미지(`sNN.png`)를 올린다.
2. 콘티의 "Grok 영상" 프롬프트를 붙여 넣는다.
3. 길이는 항상 **6초**. 장면이 길면 콘티에 `S01-1`, `S01-2`처럼 클립이 나뉘어 있다 — `-2`는 `images/s01-2.png`를 올려서 만든다. 남는 부분은 합성 때 잘린다.
4. 받은 파일을 `clips/sNN.mp4`로 저장.
5. 확인할 것: 인물이 바뀌지 않는지, 말소리·음악이 섞였는지(섞였으면 다시 만들거나 그 장면 `sfx_volume: 0`).

## 잘 안 될 때

| 문제 | 해결 |
|---|---|
| 장면마다 얼굴·옷이 달라짐 | 캐릭터 이미지를 꼭 첨부, "same character as the attached reference" 강조 |
| 이미지에 글자가 들어감 | "no text" 강조 후 다시 생성 |
| Grok이 엉뚱하게 움직임 | 동작을 한 가지로 줄여서 다시 (예: "pours water slowly") |
| 클립 앞부분만 이상함 | 다시 만들지 말고 장면에 `trim_start: 초` |
| Grok 길이보다 장면이 김 | 합성 시 최대 1.35배 느리게 늘리고, 그래도 모자라면 마지막 프레임 유지 |
| 모든 시도가 실패 | 그 장면은 `source: still`로 바꿔 이미지 느린 줌 |

## 화풍 바꾸기

`styles/3d-cartoon.yaml`을 복사해 새 이름으로 만들고 `image_prefix` 등을 고친 뒤,
`episode.yaml`에 `style: <새이름>` (이번 편만) 또는 `config/project.yaml`의 `style.default` (전체).
`python aw.py conti <ep>`를 다시 실행하면 프롬프트가 새 화풍으로 바뀐다.

## 제목 자리 비우기 · 몇 장만 다시 만들기 (2026-10-28)

- 016~018·023·025 러프 컷에서 주인공 얼굴·손이 위쪽 제목(중심 y 279)에 자주 가렸다.
  화풍 프리셋(`styles/*.yaml`)이 이제 "위쪽 1/4 비우기, 머리는 위에서 35~45%, 무릎·허리 위 구도"를 모든 이미지에 붙이고,
  Grok에는 "카메라가 올라가 얼굴이 위쪽 1/4로 가지 않게"를 붙인다.
  `image_prompt`를 쓸 때도 팔을 머리 위로 드는 동작, 카메라 tilt up / rise, 주인공이 화면 맨 위 높은 곳에 선 구도는 피한다.
- 러프 컷에서 몇 컷만 고쳐야 하면 `episode.yaml`에 적고 `aw.py conti`를 다시 돌린다:

```yaml
redo:
  reason: "얼굴이 제목에 가린 컷"
  images: [s01, s03, s08-2]     # 이미지 이름 (sNN, sNN-2)
```

  콘티에 "다시 만들기" 탭과 `prompts-chatgpt-redo.txt`·`prompts-grok-redo.txt`가 생긴다 (캐릭터 레퍼런스는 다시 만들지 않음 → ChatGPT 한도를 아낀다).
  다 고치면 `redo:`를 지우고 `aw.py conti`를 다시 돌리면 두 파일도 지워진다.
- 사람 없는 장면(단면도·풍경)의 -2 컷에는 그 장면 이미지를 장소 기준으로 첨부하지 않는다.
