# 팩트 체크 규칙

"옛날 사람들의 지혜" 류 이야기에는 근거 없는 전설이 많다. 주제를 확정하기 전에 확인한다.

1. **근거 2개 이상**: 대학·박물관·학술지·공공기관·고고학 보고서. 블로그·SNS 단독 근거는 쓰지 않는다.
2. **전승과 사실 구분**: 후대에 전해진 일화(예: 아르키메데스의 왕관)는 "전해진 이야기"로 다룬다.
3. **원리와 역사 구분**: 현대 실험이 원리를 보여 줘도, 당시 그 방법을 썼다는 증거는 따로 필요하다.
4. **수치는 확인된 것만**: 확인 안 된 비율·인원·무게를 만들지 않는다. 필요하면 "적당히", "조금"으로.
5. **재구성임을 밝힌다**: 인물·장면은 설명용 재구성. 유튜브 설명에 "재구성한 애니메이션" 문구.
6. **episode.yaml에 기록**: `sources`(제목 + URL), `accuracy_notes`(무엇을 단정하지 않는지).

## 주제 판정

| 판정 | 기준 | 처리 |
|---|---|---|
| 채택 | 근거 2개+, 원리와 역사 모두 확인 | 진행 |
| 조건부 | 원리는 확실, 역사적 사용은 추정 | 대본에서 추정임을 밝히고 진행 |
| 제외 | 근거가 인터넷 밈·출처 불명 | 쓰지 않는다 |
