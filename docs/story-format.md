# 대본 형식

## 스토리형 구조 (기본)

아래 구조는 그대로 두고, 내레이션을 주인공 한 명이 겪는 이야기로 쓴다 → [shorts-story 스킬](../.claude/skills/shorts-story/SKILL.md), 점검은 `python aw.py story <ep>`.

## 구조 (45~60초)

| 구간 | 내용 | 예 (폼페이) |
|---|---|---|
| 0~3초 훅 | "○○ 사람들은 + 과장 반응어" | 폼페이 사람들은 매일 멘탈이 나가버렸습니다. |
| 문제 | 무엇이 왜 곤란했나 — 눈에 보이는 장면으로 | 길 위로 빗물과 오물이 흘렀거든요. |
| 질문 | 제목의 질문을 던진다 | 그래서 길 한가운데 커다란 돌을 놓았습니다. 왜일까요? |
| 해결 | 방법을 단계로 보여 준다 | 돌 윗면을 보도 높이에 맞춰… |
| 반전/한계 | 새로 생긴 문제 하나 | 그럼 수레는 어떻게 지나갈까요? |
| 마무리 해결 | 한계를 넘는 디테일 | 돌 사이 틈으로 바퀴가 지나갑니다. |
| 정리 + 정보 | 한 문장 답 + 의외의 한 줄 정보 → **마지막 대사: "이것이 바로 ○○입니다"** (이름은 여기서 처음 공개) | 사람은 돌 위로, 물과 바퀴는 돌 사이로. |

## 길이

- 필재 원음 약 **6.2자/초**(공백 제외), 감속 없음, 문장 사이 쉼은 0.28초로 줄인다 → 속도감 있게.
- 목표: 공백 제외 **300~340자** → 영상 약 50~60초. 장면 수·클립은 그대로 두고 대사를 촘촘하게 쓴다.
- 길어도 대사를 빨리 감거나 자르지 않는다. 영상을 늘린다. 많이 길면 대본을 줄인다.

## 훅

- 첫 문장 안에 반응어. 문장은 짧게.
- 현대 화자의 과장 연출이다. 당시 기록이나 실제 발언처럼 쓰지 않는다.
- 반응어 후보: 멘탈이 나가버렸습니다 · 머리를 쥐어뜯었습니다 · 속이 터졌습니다 · 발을 동동 굴렀습니다 · 넋이 나갔습니다 · 두 손 두 발 다 들었습니다 · 골머리를 앓았습니다
- 쓴 반응어는 [topics.md](topics.md)에 기록하고 연달아 쓰지 않는다.

## 장면

- 8~11장면. 한 장면에 한 가지 생각.
- **Grok 클립은 하나에 최대 6초.** 6초(감속 포함 약 7.2초)를 넘는 장면은 `extra_clips`로 클립을 나눈다.
  대사가 두 문장이면 문장 사이 쉼에서 컷이 바뀐다. 두 번째 클립에는 `image_prompt`를 줘서 새 시작 이미지
  (`images/sNN-2.png`)를 만든다 — 같은 이미지에서 다시 시작하면 컷에서 장면이 되감긴 것처럼 보인다.
- 장면마다 대사 1~2문장. 컷은 문장 사이 쉼에서 바뀐다.
- `source: grok` — 움직임이 필요한 장면 (사람·물·수레 동작). 대부분의 장면.
- `source: still` — 단면도·비교처럼 정지 이미지가 더 명확한 장면. 느린 줌(최대 1.08배)이 들어간다.
- 같은 인물·물체를 장면 내내 유지한다 (캐릭터 기준 이미지).
- 핵심 동작은 화면 가운데(세로 620~1240px)에. 위쪽 1/5은 제목 자리라 단순하게.

## 제목 (화면 고정 제목)

- `title_lines`: 두 줄, 합쳐서 24자 안팎. 첫 줄 흰색, 둘째 줄 노란색.
- 보통 질문형: ["폼페이는 왜 길 한가운데", "돌을 놓았을까?"]

## 자막

- 대본의 모든 단어가 나온다. 한 묶음 최대 두 줄·28자·7어절.
- 자동 나눔을 `python aw.py captions <ep>`로 보고, 어색하면 직접 쓴다:

```yaml
lines:
  - text: "젖은 모래는 단단해져서, 썰매가 훨씬 쉽게 미끄러졌죠."
    captions: ["젖은 모래는 단단해져서", "썰매가 훨씬 / 쉽게 미끄러졌죠"]   # '/' = 줄바꿈
```

- `caption_keywords`에 넣은 단어는 노란색으로 강조된다 (3~6개).

## 유튜브 문구

`youtube.titles` 2~3개, `description` 2~4문장(재구성 애니메이션임을 밝힘), `hashtags` 3~5개.
